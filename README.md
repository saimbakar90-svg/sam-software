## 🚀 Overview

A comprehensive, zero-dependency, high-speed Enterprise Pharmacy & Cosmetics ERP designed specifically for pharmacies, retail medical stores, and cosmetic boutiques.

### Key Features
- **Smart POS & Billing (F2)**: High-speed barcode scanning, multi-tier unit conversions (Box / Strip / Tablet), thermal receipt printing (80mm / 58mm).
- **Dedicated Expiry & Alerts Center**: FEFO (First-Expiry-First-Out) batch dispatching, 7-day/30-day/90-day expiry risk matrix, automated POS sale blocking for expired batches.
- **Cosmetics & Beauty Catalog**: Shade/color tracking, fragrance volume, premium skincare inventory.
- **Financials & Accounting**: Double-entry ledgers, operating expense tracking, profit & loss, customer khata & distributor payables.
- **19 Complete Reports**: Real-time sales, tax/FBR audit summaries, supplier balances, dead stock telemetry.
- **Usman AI Clinical Voice Assistant (F9)**: Bilingual (Urdu / English) voice & text assistant for instant inventory and clinical queries.
- **Responsive on All Devices**: Mobile phones, tablets, laptops, and desktop computers.

## ⚡ Deploying to Vercel (1-Click Ready)

This repository is pre-configured with `vercel.json` for zero-configuration instant deployment.

### Method 1: Via Vercel Dashboard & GitHub (Recommended)
1. Push this folder to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Usman Pharmacy ERP"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   git push -u origin main
   ```
2. Log into [Vercel](https://vercel.com).
3. Click **Add New...** -> **Project**.
4. Select your GitHub repository.
5. Leave Framework Preset as **Other** (Root directory `./`).
6. Click **Deploy**. Your site will be live across the world in seconds!

### Method 2: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
